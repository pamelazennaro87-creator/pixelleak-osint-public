# SCOPE

## In scope

- Public incident disclosures about AI agents and GitHub/dev-tool data exposure
- Mechanism comparison (workaround vs prompt injection vs CI agent)
- Public tool documentation (e.g. gitshot defaults)
- Status of public locators (AVAILABLE / REMOVED)
- Correlations suggested for human review only

## Out of scope

- Collection or redistribution of leaked passwords, tokens, keys
- Victim PII dumps or internal dashboards content
- Malware binaries or weaponized prompt payloads beyond high-level description
- Claiming confirmed victim lists when researchers published only sector labels

## Governance note

Making a repository **public** does not change what is legal or ethical to store.  
This archive stays fingerprint-first whether private or public.
