# Status rules

## REPORTED
Claim appears in a citable public source. Not yet independently verified in this archive.

## OBSERVED
Analyst reviewed the primary public disclosure and/or checked a public locator (HTTP status, repo exists, tool README wording).

## CONFIRMED
Non-sensitive fact supported by multiple independent public sources **or** direct technical verification that does not require handling stolen payloads (e.g. tool default privacy wording in upstream README).

## Promotion
Promotions are logged; quantitative victim counts stay REPORTED unless independently countable from public data without collecting sensitive content.
