# Web page

Static consultable UI for the dataset.

## Open locally

Open `docs/index.html` in a browser, or:

```bash
cd docs && python3 -m http.server 8080
# http://localhost:8080
```

## GitHub Pages (optional)

Repo **Settings → Pages → Deploy from branch** → branch `main` → folder `/docs`.

Public URL will be:

`https://pamelazennaro87-creator.github.io/pixelleak-osint-public/`
